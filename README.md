# Control de Asistencia

Aplicación web responsive desarrollada para registrar y consultar la asistencia de 30 participantes durante 10 sesiones.

## Tecnologías utilizadas

- Google Apps Script
- Google Sheets
- HTML, CSS y JavaScript
- Visual Studio Code
- Node.js
- clasp
- Git y GitHub

## Funcionalidades principales

- Registro de asistencia por sesión.
- Estados de asistencia: `PRESENTE` y `AUSENTE`.
- Avance automático a la siguiente sesión.
- Bloqueo de sesiones ya registradas para evitar sobrescrituras.
- Consulta de sesiones anteriores en modo solo lectura.
- Agregar una descripción a las ausencias sin modificar el estado original.
- Interfaz adaptable para computadora y dispositivos móviles.
- Almacenamiento de la información en Google Sheets.
